# How to keep getting game updates in this chat (PLEASE READ)

Hi! This page explains one simple rule that keeps your game updates flowing.

## The one rule

**Never merge (and never close) the open Pull Request while you still want
more updates in this chat.**

When a Pull Request gets merged, the chat that opened it **permanently loses
its ability to send updates to GitHub**. That has already happened twice —
each time, the chat could not push any more fixes and you had to start a new
one.

## What happens instead (all automatic)

- Every update I make is **pushed to the branch** right away.
- Your testing link always serves the newest version from the branch
  (refresh after ~5 minutes):
  https://raw.githack.com/misualpa54-gif/Tank-Thiltete/arena/01a02138-tank-thiltete/tank_realms_v25_standalone%20(1).html
- Bookmark that link on your phone.

## When you are 100% done and happy

Say something clear like: **"merge and end the session"**.

Then — and only then — I will merge the Pull Request as the very last action.
After that, this chat is finished and the merged version becomes the
permanent link:
https://raw.githack.com/misualpa54-gif/Tank-Thiltete/main/tank_realms_v25_standalone%20(1).html

## Quick answers

- **"Publish it"** → I will push to the branch and leave the PR open. Safe.
- **Accidentally pressed "Merge pull request" on GitHub?** → Tell me; you
  will need a new chat, and I will have left everything safe on the branch.
- **Want a tweak?** → Just say it. That is exactly what the open PR allows
  me to keep doing.
